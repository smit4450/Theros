# Tag Conventions

> [!info] Purpose
> This is the **single source of truth** for all tag conventions in this vault. Pin this note or link it in your sidebar for easy reference. Review it when creating new content.

## Rules

1. Always use **lowercase**
2. Use **forward slashes** `/` for hierarchy
3. Use **hyphens** `-` for multi-word terms
4. Tags **MUST** be in YAML frontmatter (not inline `#tags` in body text)
5. Every note **MUST** have at least one `type/` tag
6. Compendium content retains its `ttrpg-cli/` tags from the CLI import
7. Custom/homebrew content uses the custom tag taxonomy below

These tags are applied by the `ttrpg-cli` 5etools import and **should not be manually edited**:

## Custom Tag Taxonomy (Hand-Curated)

Use these tags on **homebrew, lore, campaign, and custom content** — anything not auto-generated by the CLI.

### Type Tags (Required on every custom note)
- `type/location` — A place in the world
- `type/npc` — A non-player character
- `type/faction` — An organization or group
- `type/deity` — A god or divine being
- `type/event` — A historical or campaign event
- `type/item` — A homebrew item
- `type/creature` — A homebrew creature
- `type/quest` — A quest or mission
- `type/lore` — World lore, history, mythology
- `type/class` — A homebrew class or subclass
- `type/rule` — A homebrew or house rule
- `type/utility` — Meta/utility notes (dashboards, tables, etc.)

### Place Tags (For locations)
- `place/continent`
- `place/nation`
- `place/region`
- `place/polis` — City-state (Theros-specific)
- `place/city`
- `place/town`
- `place/village`
- `place/building`
- `place/dungeon`
- `place/wilderness`
- `place/divine-realm` — Nyx and divine domains

### Location Hierarchy
```
loc/theros/[region]/[settlement]
```
Examples:
- `loc/theros/meletis`
- `loc/theros/akros`
- `loc/theros/setessa`
- `loc/theros/nyx`

### Status Tags
- `status/active` — Currently in use/relevant
- `status/destroyed` — No longer exists in-world
- `status/abandoned` — Exists but unused
- `status/planned` — Planned but not yet introduced
- `status/wip` — Work in progress (note is incomplete)
- `status/complete` — Note is finished

### Campaign Tags
- `campaign/main` — Main campaign content
- `campaign/side-quest` — Side quest content
- `campaign/backstory` — Background/history content
- `campaign/homebrew` — Custom homebrew mechanics

### Relevance Tags
- `relevance/critical` — Essential to the campaign
- `relevance/major` — Important but not essential
- `relevance/minor` — Minor detail
- `relevance/flavor` — Atmospheric/flavor only

### Source Tags (for homebrew)
- `source/homebrew` — Original homebrew content
- `source/adapted` — Adapted from published material
- `source/theros-block` — From MTG Theros block lore
- `source/theros-beyond-death` — From MTG Theros: Beyond Death lore

### Theros-Specific Tags
- `pantheon/theros` — Related to Theros pantheon
- `domain/[domain-name]` — Divine domain (forge, knowledge, light, etc.)
- `faction/[faction-name]` — In-world factions

## Frontmatter Examples

### Homebrew Location
```yaml
---
title: The Siren's Rest
tags:
  - type/location
  - place/building
  - loc/theros/meletis
  - status/active
  - campaign/main
  - relevance/major
  - source/homebrew
aliases:
  - Siren's Rest
  - The Siren's Rest Tavern
---
```

### Homebrew NPC
```yaml
---
title: Kynaios the Wanderer
tags:
  - type/npc
  - loc/theros/akros
  - faction/iroas-champions
  - campaign/main
  - relevance/critical
  - source/homebrew
aliases:
  - Kynaios
---
```

### Lore Note
```yaml
---
title: The Silence of the Gods
tags:
  - type/lore
  - pantheon/theros
  - campaign/backstory
  - relevance/major
  - source/theros-beyond-death
  - status/complete
aliases: []
---
```

```yaml
---
title: The Warlord Class
tags:
  - type/class
  - campaign/homebrew
  - status/wip
  - source/homebrew
aliases:
  - Warlord
---
```
